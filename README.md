# AI Video Studio (8–10 Min Video Stories)

Веб-платформа для автоматической генерации 8–10 минутных видеоисторий (видеороликов из 30–35 кадров) с дикторской озвучкой, синхронными субтитрами и широкоформатными кинематографичными иллюстрациями.

## Основной стек
- **Frontend / Backend**: Next.js 14 (App Router), React, Tailwind CSS
- **База данных и хранилище**: Supabase (PostgreSQL, Storage bucket `video-assets`)
- **ИИ модели**:
  - **GPT-4o**: сценарий видеоистории, деление сюжета на 30–35 связанных кадров
  - **OpenAI TTS (`tts-1`)**: озвучка каждого кадра голосами Onyx, Nova, Alloy, Echo и др.
  - **OpenAI DALL-E 3**: широкоформатные кинематографичные иллюстрации 16:9 под текст
- **Экспорт**:
  - В браузере (через Canvas + MediaRecorder без нагрузки на сервер)
  - Локально через Docker Desktop (FFmpeg 1080p MP4)

---

## Архитектура доступа и квот
1. Пользователь заходит на главную страницу, вводит своё **Имя** и **Секретный код**.
2. Если код новый, его статус переходит в `pending` (Ожидает одобрения).
3. Администратор заходит в панель `/admin` по мастер-паролю (`ADMIN_SECRET_KEY`) и нажимает кнопку **«Одобрить»**.
4. После одобрения пользователю доступно **10 генераций** (1 генерация = 1 видеоролик на 8–10 минут из 30–35 кадров).
5. При каждой успешной генерации счетчик уменьшается на 1.
6. Администратор может начислять дополнительные генерации (+10) или создавать новые инвайт-коды.

---

## Локальный запуск
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Скопируйте `.env.example` в `.env.local` и укажите ключи.
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте `http://localhost:3000`.

---

## Локальный рендер через Docker Desktop (опционально)
Если вам требуется экспортировать сырой 1080p MP4 файл через FFmpeg:
```bash
docker compose -f docker/docker-compose.yml up
```
