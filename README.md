# AI Video Studio

Веб-платформа для генерации видеоисторий длительностью от 1 до 15 минут: сплошной
закадровый рассказ, синхронные субтитры и кинематографичные иллюстрации к каждому кадру
с эффектом Ken Burns. Формат кадра выбирается перед запуском — горизонтальный 16:9 или
вертикальный 9:16. Бюджет картинок: 5 кадров на 1 минуту, 30 кадров на 15 минут, линейно,
больше 30 картинок на фильм не бывает.

> Полное техническое описание для нового разработчика — роли, вход, сервер,
> DNS, все ключи и где они лежат: **[docs/PROJECT.md](docs/PROJECT.md)**.

## Стек

- **Frontend / Backend**: Next.js 14 (App Router), React 18, Tailwind CSS 3
- **База и хранилище**: SQLite одним файлом (`node:sqlite`, без нативных модулей)
  и файлы на диске сервера; отдаются nginx по `/media`
- **Сервер**: свой VPS (Ubuntu 24.04), Node 24 + systemd + nginx, TLS Let's Encrypt,
  сборка в GitHub Actions, деплой по SSH — см. `docs/deploy.md`
- **Модели**:
  - **GPT-4o** — весь текст: план истории (сюжет, персонажи, биты), сплошной
    монолог, редакторская чистка, обрезка до заказанного объёма, проверка ритма и
    визуальные промпты. Одна модель по решению владельца (07.09.2026); gpt-5.1 в
    пайплайне не используется — замер показал, что монолог он пишет в 1,5–2 раза
    длиннее заказа. Проходы и usage — `src/lib/script/model.ts`, `src/lib/llm-usage.ts`
  - **ElevenLabs** — озвучка, только `eleven_v3` для всех трёх языков (единственная
    модель с казахским). Multilingual v2 и запасная озвучка OpenAI убраны: если
    ElevenLabs не ответил, генерация останавливается с понятной ошибкой. Голоса —
    по четыре на язык (`src/lib/content/voices.data.json`): русские и часть казахских
    взяты из библиотеки ElevenLabs и добавлены в аккаунт владельца
  - **gpt-image-1-mini** — иллюстрации, 1536×1024 или 1024×1536, JPEG 95 % прямо из
    API (≈0,5 МБ вместо 2–3 МБ PNG, на глаз без потерь). Стиль картинок не выбирается:
    по умолчанию кино-фотореализм, другой — только если он прямо назван в теме
    (план истории возвращает `visualStyle`)
- **Экспорт**: полностью в браузере. Основной путь — WebCodecs H.264/AAC + `mp4-muxer`;
  где WebCodecs нет (iOS Safari, Firefox) — запись через MediaRecorder в реальном времени.
  Любой фильм можно собрать и как 16:9, и как 9:16 (центр-кроп), в 1080p или 720p.

## Языки

Интерфейс всегда русский. Язык **контента и озвучки** выбирается отдельно: русский,
казахский или английский. Каталоги жанров, стилей, тем и голосов лежат в
`src/lib/content/` — это единственный источник правды и для интерфейса, и для
серверных роутов, и для `scripts/gen-voice-samples.mjs`.

## Доступ и ключи

Одна форма входа на главной: **почта + код доступа**. Писем сайт не шлёт, паролей
не хранит. Сессия — подписанная HttpOnly-cookie, скриптом её из браузера не достать.

**Пользователь**

1. Администратор создаёт в панели **код доступа** (`KZ-XXXX-XXXX` или свой) и
   передаёт его человеку лично.
2. Человек вводит почту и код. При первом входе код привязывается к этой почте
   и дальше работает только с ней — постоянный пропуск, сессия на 30 дней.
3. Сразу после входа открывается окно «Мои ключи»: **ElevenLabs** (озвучка) и
   **OpenAI** (текст и картинки). Оба хранятся зашифрованными AES-256-GCM, наружу
   не отдаются; без обоих кнопка запуска заблокирована.
4. Лимитов нет: все расходы идут со счетов пользователя. В студии он видит живой
   остаток кредитов ElevenLabs, состояние ключа OpenAI и прикидку списаний под
   слайдером хронометража («OpenAI ≈ $…, ElevenLabs ≈ … кредитов ≈ $…»).
   Фактическую стоимость фильмов видит только администратор.

**Администратор**

- Главный — `ADMIN_EMAIL` на сервере; код администратора хранится только
  scrypt-хэшем (`ADMIN_CODE_HASH`, `node scripts/hash-code.mjs "<код>"`).
- Вход той же формой на главной: почта администратора + код администратора →
  сразу `/admin` (сессия 12 часов). Можно войти и прямо на `/admin`. Та же
  почта с кодом доступа открывает обычную студию — администратор может быть и
  пользователем.
- Других администраторов он добавляет в панели по почте; они входят своей почтой
  и тем же кодом администратора и тоже попадают в панель.
- В панели: коды доступа (создать, отозвать), пользователи (новый код, сброс
  ключей, блокировка, удаление с файлами), все фильмы со стоимостью и плеером,
  журнал отказов пайплайна, администраторы, расход диска.

Лимиты попыток с IP хранятся в базе (`login_attempts`): вход — 20 за час,
администратор — 10 за час с адреса и 20 за час со всех адресов; на неверный код
сервер отвечает с задержкой 0,7–1,3 с.

## Референс (необязательно)

В плитке «Сюжет» можно приложить картинку-образец (PNG/JPG/WebP до 8 МБ). GPT-4o
описывает её вид — технику, палитру, свет, настроение (`src/lib/reference.ts`) —
и этот вид получают все кадры вместо стиля по умолчанию; настроение картинки
подсказывается и плану истории. Если на картинке явный герой или предмет, он
становится героем истории, и сама картинка прикладывается к каждому запросу
`images/edits`, чтобы герой оставался узнаваемым; без героя кадры рисуются
текстовым описанием стиля через `images/generations`. Вызов распознавания и
входная картинка (image input $2,50 / 1M токенов) учитываются в стоимости фильма.

## Субтитры

Кегль — 5,2 % короткой стороны кадра для 16:9 и 5 % для 9:16; подложки нет, текст с чёрной
обводкой, не больше двух строк (длинное предложение делится на две реплики). Цвет никто
не выбирает: каждое предложение берёт следующий из шести цветов (белый, жёлтый, красный,
синий, фиолетовый, зелёный) по сквозному номеру предложения в фильме — одинаково в превью
и в MP4 (`src/lib/subtitles.ts`, `src/lib/export/render.ts`). В плеере субтитры сидят у
нижнего края (7 % высоты) и поднимаются ровно над панелью управления, пока она видна.

## Стоимость фильма

Стоимость видит только администратор — во вкладке «Фильмы» компактной строкой и
в окне «Расчёт стоимости» с таблицей по статьям: текст (GPT-4o, токены из `usage`, $2,50 вх. / $10 исх. за 1M),
картинки (gpt-image-1-mini medium, $0,015 за штуку × число кадров), озвучка
(ElevenLabs `eleven_v3`; точные списания берутся из `/v1/history` по
`request_id`, счётчик — из `/v1/user/subscription` до и после). Тариф
ElevenLabs один: **Starter $6/мес + Pay As You Go** — кредиты подписки в расчёт
не входят, каждый потраченный кредит считается по $0,10 за 1 000. Прикидка под
слайдером берёт ~0,55 кредита за символ (наблюдаемое списание), факт — всегда
по истории. Старые записи с двумя тарифами приводятся к этому виду при показе
(`normalizeCost`). Цены и источники — `src/lib/pricing.ts`.

## Локальный запуск

> **Важно.** Путь проекта содержит `#`. Next формирует ключи React Client Manifest
> как `путь#экспорт`, поэтому лишний `#` ломает разбор, и любая страница падает с
> `Could not find the module … .js#` — и в dev, и в build. Симлинк и junction не
> помогают: и webpack, и Node разворачивают их в реальный путь. Рабочий обход —
> подменить путь буквой диска. Постоянное решение — убрать `#` из имени папки.

```bash
subst X: "C:\Users\oatmeal\Desktop\Nurtaskot#08"
```

Затем:

```bash
npm install
```

```bash
X: && npm run dev
```

Откройте `http://localhost:3000`. Переменные — в `.env.local`, полный список с
пояснениями лежит в `.env.example`. Минимум для работы: `SESSION_SECRET`,
`ADMIN_EMAIL`, `ADMIN_CODE_HASH`. Нужен **Node 24 или новее** (модуль
`node:sqlite`). База и медиа лежат в `.data/` рядом с проектом.

Ключей OpenAI и ElevenLabs в окружении нет: генерация идёт с ключей
пользователей. Для `scripts/gen-voice-samples.mjs` передайте `ELEVENLABS_API_KEY`
переменной окружения.

## Демо-сэмплы голосов

```bash
node scripts/gen-voice-samples.mjs
```

Генерирует только недостающие файлы; `--all` перегенерирует все, `--lang=en` — один язык.
Скрипт читает тот же каталог и те же настройки синтеза, что и рантайм, поэтому превью
в интерфейсе и реальная озвучка не расходятся.

## База и файлы

Схема создаётся сама при первом обращении и версионируется через
`PRAGMA user_version` (`src/lib/db.ts`) — отдельного шага миграции при деплое
нет. Таблицы: `users`, `admins`, `invite_codes`, `login_codes`,
`login_attempts`, `video_generations`, `settings`.

Кадры и озвучка лежат на диске (`src/lib/storage.ts`):
`films/<videoId>/scene_N.jpg|mp3` (фильмы до 07.09.2026 — `png`) и `refs/<userId>/<uuid>.png`, наружу уходят
ссылками `/media/...`. В production их отдаёт nginx прямо с диска, в разработке
тот же путь обслуживает роут `src/app/media/[...path]`.

Уборщик (`scripts/cleanup.mjs`, таймер systemd раз в сутки) стирает картинки и
звук фильмов старше `MEDIA_TTL_DAYS` (30 дней), удаляет папки без записи в базе
и чистит просроченные коды. Текст сцен и стоимость остаются навсегда.

## Сервер и деплой

Инструкция целиком — `docs/deploy.md`: заказ VPS, `deploy/server-setup.sh`,
GitHub Actions, бэкап и восстановление. Коротко: push в `main`
→ сборка в Actions → готовый `standalone` уезжает по SSH → `systemctl restart
studio`.
