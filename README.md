# AI Video Studio

Веб-платформа для генерации видеоисторий длительностью от 1 до 10 минут: сплошной
закадровый рассказ, синхронные субтитры и кинематографичные иллюстрации к каждому кадру.
Формат кадра выбирается перед запуском — горизонтальный 16:9 или вертикальный 9:16.

## Стек

- **Frontend / Backend**: Next.js 14 (App Router), React 18, Tailwind CSS 3
- **База и хранилище**: Supabase (PostgreSQL + Storage bucket `video-assets`)
- **Модели**:
  - **GPT-4o** — сценарий в три прохода: план истории → один непрерывный монолог →
    визуальные промпты к уже нарезанным фрагментам
  - **ElevenLabs** — озвучка. Модель выбирается по языку: `eleven_multilingual_v2`
    для русского и английского, `eleven_v3` для казахского (его нет в языковом
    покрытии multilingual_v2). Запасной путь — OpenAI `gpt-4o-mini-tts`
  - **gpt-image-1-mini** — иллюстрации, 1536×1024 или 1024×1536
- **Экспорт**: полностью в браузере — WebCodecs H.264/AAC + `mp4-muxer`, 1080p @ 30 FPS.
  Серверного рендера и FFmpeg в проекте нет.

## Языки

Интерфейс всегда русский. Язык **контента и озвучки** выбирается отдельно: русский,
казахский или английский. Каталоги жанров, стилей, тем и голосов лежат в
`src/lib/content/` — это единственный источник правды и для интерфейса, и для
серверных роутов, и для `scripts/gen-voice-samples.mjs`.

## Доступ и квоты

1. Пользователь вводит пароль или инвайт-код на главной странице.
2. Новый код получает статус `pending` и ждёт одобрения.
3. Администратор заходит в `/admin` по мастер-паролю и одобряет код.
4. После одобрения доступен заданный лимит генераций; при каждой успешной
   генерации счётчик уменьшается на 1.
5. Администратор может менять лимит, создавать инвайт-коды, **временно замораживать**
   аккаунты (24 часа / 7 дней / бессрочно) и смотреть **лог отказов** по этапам
   пайплайна: сценарий, озвучка, картинки, рендер.

Токен админ-сессии подписан HMAC на `ADMIN_SECRET_KEY` и живёт 12 часов.

Защита от перебора на входе: 10 неверных попыток с одного IP — блокировка на 24 часа.

## Локальный запуск

> **Важно.** Путь проекта содержит `#`. Next формирует ключи React Client Manifest
> как `путь#экспорт`, поэтому лишний `#` ломает разбор, и любая страница падает с
> `Could not find the module … .js#` — и в dev, и в build. Симлинк и junction не
> помогают: и webpack, и Node разворачивают их в реальный путь. Рабочий обход —
> подменить путь буквой диска. Постоянное решение — убрать `#` из имени папки.

```bash
subst X: "C:\Users\oatmeal\Desktop\Nurtaskot#08"
```

Затем:

```bash
npm install
```

```bash
X: && npm run dev
```

Откройте `http://localhost:3000`. Ключи — в `.env.local`:
`OPENAI_API_KEY`, `ELEVENLABS_API_KEY`, `NEXT_PUBLIC_SUPABASE_URL`,
`NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_SECRET_KEY`.

## Демо-сэмплы голосов

```bash
node scripts/gen-voice-samples.mjs
```

Генерирует только недостающие файлы; `--all` перегенерирует все, `--lang=en` — один язык.
Скрипт читает тот же каталог и те же настройки синтеза, что и рантайм, поэтому превью
в интерфейсе и реальная озвучка не расходятся.

## Миграции

`supabase/migrations/` — SQL изменений схемы. Исторически схема правилась вручную в
консоли Supabase, поэтому файлы там появились позже кода; применять их нужно вручную
через SQL Editor в панели Supabase.
