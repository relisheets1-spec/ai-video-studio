# AI Video Studio

Веб-платформа для генерации видеоисторий длительностью от 1 до 15 минут: сплошной
закадровый рассказ, синхронные субтитры и кинематографичные иллюстрации к каждому кадру
с эффектом Ken Burns. Формат кадра выбирается перед запуском — горизонтальный 16:9 или
вертикальный 9:16. Бюджет картинок: 5 кадров на 1 минуту, 30 кадров на 15 минут, линейно,
больше 30 картинок на фильм не бывает.

## Стек

- **Frontend / Backend**: Next.js 14 (App Router), React 18, Tailwind CSS 3
- **База и хранилище**: Supabase (PostgreSQL + Storage bucket `video-assets`)
- **Модели**:
  - **GPT-4o** — сценарий в два этапа (лимит функции Vercel 300 с): план истории с миром
    и локациями → один непрерывный монолог; затем редакторская чистка повторов и длинных
    предложений → проверка ритма (доля коротких фраз, длинные серии) и, если нужно,
    проход «ритм» → визуальные промпты с непрерывностью места и света внутри бита
  - **ElevenLabs** — озвучка, только `eleven_v3` для всех трёх языков (единственная
    модель с казахским). Multilingual v2 и запасная озвучка OpenAI убраны: если
    ElevenLabs не ответил, генерация останавливается с понятной ошибкой. Голоса —
    по четыре на язык (`src/lib/content/voices.data.json`): русские и часть казахских
    взяты из библиотеки ElevenLabs и добавлены в аккаунт владельца
  - **gpt-image-1-mini** — иллюстрации, 1536×1024 или 1024×1536
- **Экспорт**: полностью в браузере. Основной путь — WebCodecs H.264/AAC + `mp4-muxer`;
  где WebCodecs нет (iOS Safari, Firefox) — запись через MediaRecorder в реальном времени.
  Любой фильм можно собрать и как 16:9, и как 9:16 (центр-кроп), в 1080p или 720p.

## Языки

Интерфейс всегда русский. Язык **контента и озвучки** выбирается отдельно: русский,
казахский или английский. Каталоги жанров, стилей, тем и голосов лежат в
`src/lib/content/` — это единственный источник правды и для интерфейса, и для
серверных роутов, и для `scripts/gen-voice-samples.mjs`.

## Доступ и квоты

Студия и админ-панель — два независимых входа, между ними нет ссылок.

**Пользователь**

1. Администратор создаёт инвайт-код в панели и передаёт его человеку.
2. Человек на главной странице открывает «Регистрация» и вводит почту, инвайт-код и
   свой ключ ElevenLabs (хранится в базе зашифрованным AES-256-GCM, озвучка идёт с него).
3. Заявка получает статус `pending`; входа в студию нет, пока администратор её не одобрит.
4. После одобрения вход — почта + инвайт-код. Токен сессии подписан HMAC, живёт 30 дней,
   но на каждом запросе к API сервер заново читает статус и заморозку аккаунта.
5. Каждая успешная генерация уменьшает баланс на 1. Без сессии `/api/videos` и
   `/api/generate/*` отвечают 401.

**Администратор**

- Основной администратор задаётся переменной `ADMIN_EMAIL` (и продублирован в таблице
  `admins`). Вход в `/admin` — почта + пароль администратора; пароль хранится scrypt-хэшем,
  меняется во вкладке «Настройки».
- Только основной администратор назначает и снимает других администраторов по почте
  (вкладка «Администраторы»). Все входят по одному паролю; после его смены все
  админ-сессии завершаются.
- В панели: одобрение/отклонение заявок, баланс, заморозка (24 ч / 7 дней / бессрочно),
  сброс инвайт-кода, лог отказов пайплайна.

Лимиты попыток хранятся в базе (`login_attempts`): вход — 10 ошибок за сутки с IP,
регистрация — 5 за час, админ — 10 за сутки.

## Референс персонажа (необязательно)

В плитке «Сюжет» можно загрузить картинку героя или объекта (PNG/JPG/WebP до 8 МБ).
GPT-4o описывает, кто на ней и в каком стиле (`src/lib/reference.ts`), это описание
попадает в план и в промпты кадров, а сама картинка уходит в `images/edits` как образец —
все кадры рисуются этим персонажем в этом стиле, выбранный визуальный стиль игнорируется.
Без референса генерация идёт как обычно. Доплата за входную картинку (image input
$2,50 / 1M токенов) и вызов распознавания учитываются в стоимости фильма.

## Субтитры

Кегль — 5,2 % короткой стороны кадра для 16:9 и 5 % для 9:16; подложки нет, текст с чёрной
обводкой, не больше двух строк (длинное предложение делится на две реплики). Цвет никто
не выбирает: каждое предложение берёт следующий из шести цветов (белый, жёлтый, красный,
синий, фиолетовый, зелёный) по сквозному номеру предложения в фильме — одинаково в превью
и в MP4 (`src/lib/subtitles.ts`, `src/lib/export/render.ts`). В плеере субтитры сидят у
нижнего края (7 % высоты) и поднимаются ровно над панелью управления, пока она видна.

## Стоимость фильма

У каждого нового видео в архиве есть строка стоимости и модалка «Стоимость» с таблицей
по статьям: текст (gpt-4o, токены из `usage`), картинки (gpt-image-1-mini, $0,015 за штуку
по официальной таблице), озвучка (ElevenLabs `eleven_v3`; точные списания берутся из
`/v1/history` по `request_id`, остаток — из `/v1/user/subscription` до и после; на
аккаунте Creator история показывает около 0,55 кредита за символ, поэтому прикидка под
слайдером считает по этому коэффициенту, а факт — всегда по истории).
Итог показан по двум сценариям ElevenLabs: Creator $22/мес за 130 372 кредита и
Starter $6/мес + Pay As You Go ($0,10 за 1 000 кредитов, живут 12 месяцев). Чистого
Pay As You Go нет — без подписки API недоступен. Цены и источники — в `src/lib/pricing.ts`.

## Локальный запуск

> **Важно.** Путь проекта содержит `#`. Next формирует ключи React Client Manifest
> как `путь#экспорт`, поэтому лишний `#` ломает разбор, и любая страница падает с
> `Could not find the module … .js#` — и в dev, и в build. Симлинк и junction не
> помогают: и webpack, и Node разворачивают их в реальный путь. Рабочий обход —
> подменить путь буквой диска. Постоянное решение — убрать `#` из имени папки.

```bash
subst X: "C:\Users\oatmeal\Desktop\Nurtaskot#08"
```

Затем:

```bash
npm install
```

```bash
X: && npm run dev
```

Откройте `http://localhost:3000`. Переменные — в `.env.local`:
`OPENAI_API_KEY`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`,
`SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_SECRET_KEY`, `ADMIN_EMAIL`.
`ELEVENLABS_API_KEY` в окружении не нужен: озвучка идёт с ключей пользователей; без ключа
у пользователя генерация останавливается. Для `scripts/gen-voice-samples.mjs` передайте
ключ переменной окружения `ELEVENLABS_API_KEY`.

## Демо-сэмплы голосов

```bash
node scripts/gen-voice-samples.mjs
```

Генерирует только недостающие файлы; `--all` перегенерирует все, `--lang=en` — один язык.
Скрипт читает тот же каталог и те же настройки синтеза, что и рантайм, поэтому превью
в интерфейсе и реальная озвучка не расходятся.

## Миграции

`supabase/migrations/` — SQL изменений схемы, все файлы идемпотентны. Применяются через
Management API Supabase (нужны `SUPABASE_ACCESS_TOKEN` и `SUPABASE_PROJECT_ID` в `.env.local`):

```bash
node scripts/apply-migration.mjs supabase/migrations/0002_email_auth_admins.sql
```
